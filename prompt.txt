buatkan issue.md yang berisikan planning untuk nantinya diimplementasikan oleh model lain yang lebih murah/junior programmer, isi perencanaannya sebagai berikut :

buat table users di mysql dengan field:
- id (INT, AUTO_INCREMENT)
- username (VARCHAR, UNIQUE, NOT NULL)
- email (VARCHAR, UNIQUE, NOT NULL)
- password (VARCHAR, NOT NULL)(Password merupakan hash dari bcrypt)
- created_at (TIMESTAMP, DEFAULT CURRENT_TIMESTAMP)
- updated_at (TIMESTAMP, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP)
- deleted_at (TIMESTAMP)(softdelete)

buat Api untuk registrasi user baru

Endpoint : POST /api/auth/register
Request Body:
{
    "username": "johan",
    "email": "johan@yopmail.com",
    "password": "password"
}
Response Body (Success) :
{
    "message": "User registered successfully"
}
Response Body (Error) :
{
    "message": "User already exists"
}

buat endpoint untuk login

Endpoint : POST /api/auth/login
Request Body:
{
    "username": "johan",
    "password": "password"
}
Response Body (Success) :
{
    "token": "token"
}
Response Body (Error) :
{
    "message": "User not found"
}

Struktur folder di backend maupun frontend saya ini serapi mungkin dan paling best practice

jelaskan tahapan step by step yang harus dilakukan untuk mengimplementasikan fitur ini, anggap nanti yang mengimplementasikan adalah junior programmer atau model AI yang lebih murah
